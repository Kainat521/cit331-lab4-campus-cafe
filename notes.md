## HTTP
HTTP is the protocol used to transfer data between a browser and a web server. HTTPS uses encryption to protect the connection.

## CSS Specificity
CSS specificity decides which rule applies when multiple CSS rules target the same element. Inline styles generally have higher specificity than IDs, classes, and element selectors.

## Selectors
- Element selector: `p`
- Class selector: `.card`
- ID selector: `#main`
- Attribute selector: `input[required]`
- Pseudo-class: `a:hover`
- Pseudo-element: `h2::before`
